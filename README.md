# Socle — préparation CSCS

Version publiée de l'outil de révision, utilisable sur téléphone et hors ligne :
https://blushifting.github.io/socle-cscs/

Ce dépôt ne contient que l'application compilée. La source (fiches en markdown,
script de génération) reste dans le dossier local du projet ; `data.js` en est
la compilation, régénérée par `outils/build.py` puis republiée ici.
